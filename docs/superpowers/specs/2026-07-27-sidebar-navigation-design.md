# 좌측 사이드바 내비게이션 설계

## 목표

기존 상단 헤더를 데스크톱에서 폭 220px의 고정 좌측 사이드바로 전환한다. 900px 이하 화면에서는 사이드바를 숨기고 좌측 상단 햄버거 버튼과 슬라이드 메뉴를 제공한다. 기존 포트폴리오의 색상, 타이포그래피, 섹션 링크는 유지한다.

## 데스크톱 구조

- 사이드바는 화면 왼쪽에 `position: fixed`, 폭 `220px`, 높이 `100vh`로 배치한다.
- 상단에는 `Y` 로고와 `YOUNGCHAN` 브랜드를 둔다.
- 중앙에는 About, Skills, Projects, Vision, Contact 링크를 세로로 배치한다.
- 하단에는 `Let's talk` 이메일 링크를 둔다.
- 페이지 본문은 사이드바와 겹치지 않도록 왼쪽 여백 `220px`을 가진다.

## 호버와 포커스 효과

- 메뉴에 마우스를 올리거나 키보드 포커스가 들어오면 글자가 오른쪽으로 `6px` 이동한다.
- 메뉴 왼쪽의 포인트 블루 선이 가로로 확장된다.
- 메뉴 글자색은 포인트 블루로 전환된다.
- 연락 버튼은 파란 배경으로 채워지고 화살표가 대각선으로 소폭 이동한다.
- 브랜드 로고는 색상이 반전되고 미세하게 확대된다.
- 전환 시간은 `200ms` 전후로 통일한다.
- `prefers-reduced-motion: reduce`에서는 이동과 확대 효과를 제거한다.

## 모바일 구조

- `900px` 이하에서는 데스크톱 사이드바를 화면 밖으로 숨긴다.
- 좌측 상단에 고정된 햄버거 버튼을 표시한다.
- 버튼을 누르면 폭 `min(280px, 85vw)`의 메뉴 패널이 왼쪽에서 들어온다.
- 패널 밖에는 반투명 어두운 오버레이를 표시한다.
- 메뉴 링크 또는 오버레이를 누르면 메뉴가 닫힌다.
- 메뉴가 열리면 햄버거 아이콘은 `X` 형태로 바뀐다.
- 햄버거 버튼에는 `aria-expanded`, `aria-controls`, 명확한 접근 가능한 이름을 제공한다.
- `Escape` 키로 메뉴를 닫을 수 있다.

## 컴포넌트 구조

브라우저 상태가 필요한 내비게이션을 `app/components/site-navigation.tsx` 클라이언트 컴포넌트로 분리한다. 이 컴포넌트가 데스크톱 사이드바, 모바일 햄버거 버튼, 모바일 패널과 오버레이를 함께 관리한다.

`app/page.tsx`는 기존 서버 컴포넌트로 유지하며, 기존 `<header>` 대신 `SiteNavigation`을 렌더링한다. 페이지 본문에는 사이드바 공간을 확보하는 전용 클래스만 추가한다.

## 상태와 동작

- `isMenuOpen: boolean` 하나로 모바일 메뉴 상태를 관리한다.
- 햄버거 버튼은 상태를 반전한다.
- 링크, 오버레이, Escape 입력은 상태를 `false`로 만든다.
- 페이지 이동이나 외부 통신은 기존 앵커 링크와 이메일 링크만 사용하므로 별도의 오류 UI는 필요하지 않다.

## 반응형과 레이아웃

- 데스크톱 본문은 사이드바를 제외한 영역에서 기존 최대 폭 계산을 유지한다.
- 900px 이하에서는 본문 왼쪽 여백을 제거한다.
- 기존 760px 모바일 카드·타이포그래피 규칙은 그대로 유지한다.
- 메뉴 패널은 프로젝트 카드와 다른 콘텐츠보다 높은 `z-index`를 사용한다.

## 검증

- 기존 상단 헤더가 제거되고 사이드바 내비게이션이 렌더링되는지 확인한다.
- 데스크톱 사이드바 폭과 본문 왼쪽 여백이 모두 220px인지 CSS에서 확인한다.
- 900px 미디어 쿼리와 모바일 메뉴 요소를 확인한다.
- 햄버거 버튼의 접근성 속성과 Escape 닫기 동작이 코드에 존재하는지 확인한다.
- 메뉴 링크가 기존 다섯 섹션을 그대로 가리키는지 확인한다.
- 전체 렌더링 테스트와 GitHub Pages 정적 빌드를 통과시킨다.
