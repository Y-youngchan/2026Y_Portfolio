# 유영찬 포트폴리오 사이트 디자인

## 목표

유영찬의 웹 개발, 프론트엔드, UI/UX 디자인, 웹서비스 기획 역량을 네 개의 프로젝트로 증명하는 신입 개발자용 한 페이지 포트폴리오를 만든다. PDF 1~4페이지에서 확립한 소개 문구와 시각 언어를 유지하되, 발표 자료를 그대로 옮기지 않고 웹에서 읽고 탐색하기 좋은 구조로 재구성한다.

## 대상

- 신입 웹·프론트엔드 개발자를 채용하는 실무자
- UI/UX 감각과 웹서비스 기획 역량을 함께 확인하려는 면접관
- 프로젝트의 실제 코드와 서비스를 빠르게 검토하려는 개발자

## 핵심 메시지

- 직접 아이디어를 구현하며 성취하는 개발자
- 프론트엔드부터 백엔드, 데이터 연결, AI까지 경험한 지원자
- 비전공 경험을 다양한 관점과 빠른 학습력으로 전환하는 지원자
- 모르는 것을 동료와 함께 학습하고 해결하는 협업형 개발자

## 시각 디자인

- 사진을 사용하지 않고 큰 타이포그래피와 프로젝트 정보를 중심으로 구성한다.
- PDF의 시각 언어를 이어받아 연한 라벤더 배경, 짙은 네이비 본문, 선명한 블루 강조색을 사용한다.
- 넉넉한 여백과 큰 섹션 번호로 편집 디자인의 인상을 만든다.
- 프로젝트 카드는 동일한 틀을 사용하되 큰 번호와 역할 태그로 빠르게 구분한다.
- 장식은 CSS 기반 선, 면, 그라데이션으로 제한하며 불필요한 이미지는 사용하지 않는다.
- 데스크톱은 넓은 2열 구성을 활용하고 모바일은 한 열로 재배치한다.

## 상호작용

- 고정 상단 메뉴에서 About, Skills, Projects, Vision, Contact로 이동한다.
- 메뉴 클릭 시 같은 페이지 안에서 부드럽게 스크롤한다.
- 프로젝트 링크는 새 탭에서 연다.
- 버튼과 프로젝트 카드에 짧은 hover·focus 반응을 제공한다.
- 섹션은 가벼운 등장 효과를 사용하되, 동작 줄이기 설정을 사용하는 방문자에게는 애니메이션을 제거한다.

## 구현 구조

- React 기반 단일 페이지 사이트로 구현한다.
- 페이지 섹션은 Hero, About, Skills, Projects, WorkStyle, Vision, Contact 컴포넌트로 나눈다.
- 기술과 프로젝트 내용은 별도 데이터 배열로 관리해 문구와 링크를 쉽게 수정할 수 있게 한다.
- 서버, 로그인, 데이터 저장 기능은 사용하지 않는다.
- 모든 콘텐츠는 정적 데이터이며 외부 이동은 GitHub, Hugging Face, 이메일 링크로 제한한다.

## 오류 및 예외 처리

- 외부 링크에는 안전한 새 탭 속성을 적용한다.
- 링크가 연결되지 않더라도 나머지 포트폴리오 탐색에는 영향을 주지 않는다.
- JavaScript가 느리게 실행되는 환경에서도 핵심 글과 링크가 먼저 읽히도록 구성한다.
- 긴 직무명과 기술명이 작은 화면에서 잘리거나 가로 스크롤을 만들지 않도록 줄바꿈을 허용한다.

## 검증 기준

- 데스크톱과 모바일에서 모든 내용이 잘림 없이 읽힌다.
- 메뉴가 정확한 섹션으로 이동한다.
- 키보드만으로 메뉴, 버튼, 프로젝트 링크를 사용할 수 있다.
- 이메일, GitHub, 각 프로젝트 링크가 정확하다.
- 색상 대비가 충분하고 focus 상태가 명확하다.
- 동작 줄이기 설정에서 불필요한 애니메이션이 비활성화된다.
- 제작 완료 후 배포용 빌드가 성공한다.
