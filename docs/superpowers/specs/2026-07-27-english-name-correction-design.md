# 영어 이름 표기 수정 디자인

## 목표

포트폴리오에서 방문자에게 표시되는 유영찬의 영어 이름을 실제 사용 표기인 `Yu Youngchan`으로 통일한다.

## 변경 범위

- 페이지 푸터의 `YOO YOUNGCHAN`을 `YU YOUNGCHAN`으로 수정한다.
- 공유용 대표 이미지의 영어 이름을 `YU YOUNGCHAN`으로 수정한다.
- 대문자 스타일을 사용하는 영역에서는 시각적 일관성을 위해 `YU YOUNGCHAN`으로 표시한다.
- 실제 계정 주소인 `github.com/Y-youngchan`과 각 저장소 링크는 변경하지 않는다.
- 한글 이름 `유영찬`, 페이지 구성, 색상, 문구 및 배포 주소는 변경하지 않는다.

## 구현 방식

텍스트 표기는 기존 React 페이지에서 직접 수정한다. 공유 이미지는 현재 디자인의 색상, 구성, 비율을 유지하면서 이름 표기만 수정한 새 이미지로 교체한다. 이미지 대체 텍스트와 메타데이터 연결 방식은 그대로 유지한다.

## 검증

- 소스와 생성 결과에 잘못된 방문자용 표기 `YOO YOUNGCHAN`이 남아 있지 않은지 확인한다.
- `YU YOUNGCHAN`이 페이지에 렌더링되는지 자동 검사한다.
- GitHub 링크가 기존 주소로 유지되는지 확인한다.
- 전체 빌드와 기존 포트폴리오 검사 네 항목을 다시 실행한다.
